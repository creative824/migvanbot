# בוט טלגרם להצעות מחיר – מגוון מדיה קריאייטיב

בוט טלגרם שמקבל פרטים בסיסיים (שם עסק, ח.פ, מחירים, כמות נגנים, סוג מוזיקה,
ואופציונלית לוגו של הלקוח) ומחזיר **קובץ PDF** של הצעת מחיר בעיצוב הקיים של מגוון –
שלושה עמודים, זהה למסמך `reference_sample.pdf`.

* התאריך נלקח אוטומטית מהיום שבו מפיקים את ההצעה.
* בחירת "מוזיקה ללא זכויות" → בהערות נכתב שהלקוח יקבל מסמך אישור השמעת מוזיקה ללא זכויות.
* בחירת "מוזיקה עם זכויות" → בהערות נכתב שהתשלום לגופי הזכויות חל על הלקוח.
* אם מוזנת כמות נגנים גדולה מ‑1 – מתווספת שורת סיכום עם סה"כ חודשי וסה"כ התקנה (לפני מע"מ).

---

## שלב 1 – יצירת הבוט בטלגרם (פעם אחת, 2 דקות)

1. בטלגרם פותחים צ'אט עם **@BotFather**.
2. שולחים `/newbot`, נותנים שם ושם משתמש (חייב להסתיים ב‑`bot`).
3. BotFather מחזיר **טוקן** במבנה `123456789:AAxxxxxxxx...` – שומרים אותו, זה סוד.

---

## שלב 2 – הפעלה

יש שתי דרכים. שתיהן משתמשות באותו קוד.

### דרך א' – בענן (מומלץ, פועל 24/7 בלי תלות במחשב)

הענן חינמי בהתחלה. חלק מהשירותים מבקשים כרטיס אשראי לאימות (לא מחייבים), או
"מרדימים" את השירות אחרי חוסר פעילות. אם רוצים יציבות מלאה – שרת ייעודי עולה ~₪15–25 לחודש.

הקוד כבר כולל `Dockerfile`, כך שכל פלטפורמה שמריצה Docker תעבוד. דוגמה עם **Railway**:

1. פותחים חשבון (חינם) ב‑<https://railway.app> וב‑<https://github.com>.
2. מעלים את התיקייה `quote-bot` ל‑repo חדש ב‑GitHub
   (ב‑GitHub Desktop: *Add Local Repository* → *Publish*).
3. ב‑Railway: **New Project → Deploy from GitHub repo** ובוחרים את ה‑repo.
   Railway מזהה את ה‑`Dockerfile` אוטומטית.
4. בלשונית **Variables** מוסיפים:
   * `BOT_TOKEN` = הטוקן מ‑BotFather
   * (רשות) `PRESENTER_NAME`, `PRESENTER_PHONE`
   * (רשות) `ALLOWED_USER_IDS` = מזהי טלגרם מורשים, מופרדים בפסיק
5. Railway בונה ומריץ. מרגע זה הבוט חי – שולחים לו הודעה בטלגרם.

> חלופות זהות ברעיון: **Render** (סוג שירות: *Background Worker*, מ‑Dockerfile),
> **Fly.io** (`fly launch` מזהה את ה‑Dockerfile).

### דרך ב' – על המחשב (Windows)

דורש התקנת Python פעם אחת (<https://www.python.org/downloads/> – לסמן "Add to PATH").

1. מעתיקים את `.env.example` לקובץ בשם `.env` וממלאים בו `BOT_TOKEN=...`.
2. מריצים בלחיצה כפולה על **`run_local.bat`**.
   בהרצה הראשונה הוא מתקין הכל (כולל דפדפן Chromium) – כמה דקות. אחר כך מהיר.
3. כל עוד החלון פתוח – הבוט פעיל. לסגירה: Ctrl+C או סגירת החלון.

הרצה ידנית (למי שמעדיף שורת פקודה):

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m playwright install chromium
python bot.py
```

### דרך ג' – Docker מקומי

```bash
docker build -t migvan-quote-bot .
docker run -e BOT_TOKEN=xxxxx --rm migvan-quote-bot
```

## שלב 3 – שימוש בבוט

שולחים לבוט הודעה. שתי אפשרויות:

**1. שאלון מודרך** – שולחים `/new` והבוט שואל שאלה‑שאלה:
שם העסק → ח.פ → כתובת (אפשר "דלג") → מחיר חודשי לנגן → מחיר התקנה לנגן →
כמות נגנים → סוג מוזיקה (כפתורים) → לוגו (שולחים תמונה, או "דלג").

**2. הכל בהודעה אחת** – למשל:

```
תוציא הצעה
ממן מחסנים
434234234
מוזיקה ללא זכויות
187 לחודש לנגן
350 התקנה
```

הבוט מזהה מה הצליח לקלוט, משלים בשאלות רק את מה שחסר, מציע לצרף לוגו,
ושולח בחזרה `PDF` בשם `הצעת מחיר - <שם> - <תאריך>.pdf`.

פקודות: `/new` הצעה חדשה · `/cancel` ביטול · `/start` הסבר.

## התאמות

| מה לשנות | איפה |
|---|---|
| שם וטלפון של מגיש ההצעה | משתני סביבה `PRESENTER_NAME` / `PRESENTER_PHONE` (או `config.py`) |
| מי מורשה להשתמש בבוט | `ALLOWED_USER_IDS` (ריק = כולם). מזהה מקבלים מ‑@userinfobot |
| נוסח הטקסט הקבוע / העיצוב / טבלת המחירים | `templates/quote.html` |
| כותרת/פוטר (התמונות) | `assets/header.jpg` · `assets/footer.png` |
| הפונט | `assets/fonts/Heebo.ttf` |

אחרי שינוי ב‑`templates/quote.html` אפשר לבדוק מהר בלי טלגרם:

```bash
python -c "import asyncio;from quote import QuoteData;from render import render_pdf;asyncio.run(render_pdf(QuoteData('בדיקה','123456789',187,350,qty=2),'output/preview.pdf'))"
```

## מבנה הפרויקט

```
bot.py             לוגיקת הבוט והשיחה
render.py           נתונים → HTML → PDF (Chromium/Playwright)
quote.py            מודל הנתונים + פענוח הודעה חופשית
config.py           טוקן והגדרות מתוך .env
templates/quote.html   תבנית ההצעה (3 עמודים, RTL)
assets/            כותרת, פוטר, פונט
Dockerfile         להרצה בענן / בקונטיינר
run_local.bat      הרצה בקליק אחד ב‑Windows
```

## תקלות נפוצות

* **הבוט לא מגיב** – ודאו שהתהליך רץ ושאין מופע נוסף עם אותו טוקן במקביל.
* **`חסר BOT_TOKEN`** – אין קובץ `.env` או שהמשתנה לא הוגדר בענן.
* **שגיאת Chromium / הפקת PDF נכשלת מקומית** – הריצו שוב `python -m playwright install chromium`.
* **הלוגו יוצא גדול/חתוך** – התמונה מתכווצת אוטומטית עד גובה ~26 מ"מ; רקע שקוף (PNG) נראה נקי יותר.

## מאגר הצעות ולוח בקרה

כל הצעה שהבוט מפיק נשמרת במאגר (SQLite, קובץ `quotes.db`) עם סטטוס:
⏳ ממתינה · 👀 נפתחה ע"י הלקוח · ✅ נחתמה (ע"י מי ומתי).

**בבוט:** `/list` (כפתורים: סינון הכל/ממתינות/נחתמו, דפדוף, כרטיס הצעה עם PDF / PDF חתום / קישור / וואטסאפ / שכפול / מחיקה),
`/pending`, `/signed`, `/dashboard`, וגם בטקסט חופשי: `מי לא חתם?`, `מי חתם`, `חפש פנטו`.

**באתר:** `<PUBLIC_BASE_URL>/admin` — דורש להגדיר `ADMIN_PASSWORD` (שם המשתמש חופשי).
חיפוש, סינון, הורדת PDF, העתקת קישור לחתימה, מחיקה.

**חשוב בענן:** המאגר והקבצים חייבים לשבת על דיסק קבוע, אחרת הם נמחקים בכל פריסה מחדש.
ב-Railway: על השירות → *Volumes* → *Add Volume* → Mount path `/data`.
(המשתנה `RAILWAY_VOLUME_MOUNT_PATH` נקבע אוטומטית והבוט משתמש בו.)
